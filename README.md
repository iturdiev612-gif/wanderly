# Wanderly — сайт-путеводитель

Файлы проекта:
- `index.html` — главная страница
- `kyrgyzstan.html`, `usa.html`, `spain.html`, `japan.html` — четыре страницы стран
- `style.css` — общий адаптивный дизайн, анимации и светлая/тёмная тема
- `script.js` — меню, смена языка и темы, анимации появления

## Запуск
Открой `index.html` в браузере. Для разработки можно открыть папку в VS Code и запустить через расширение Live Server.

Фото загружаются с Unsplash через интернет. Языковой переключатель переводит основные общие элементы сайта; подробные статьи стран в этой версии написаны на русском.
